# ChatGPT：复制为飞书格式

适用于桌面版 Chrome 和 Edge，使用 Manifest V3，无需构建和安装依赖。

## 安装

1. 打开 `chrome://extensions/`（Edge 使用 `edge://extensions/`）。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择 `chatgpt-plugin`。
4. **刷新已经打开的 ChatGPT 页面**。以后更新插件时，先在扩展管理页点击重新加载，再刷新 ChatGPT。

## 使用

在 `https://chatgpt.com/` 的聊天中选中内容，右键 → **ChatGPT → 复制为飞书格式**，然后粘贴到飞书文档正文。没有选区时，复制右键所在的整条消息。在消息外右键且没有选区时，会提示选择内容。

- `\[ ... \]` 和 `\( ... \)` 转成 `$$...$$`，去掉紧邻分隔符的空白。
- 已渲染的 KaTeX 公式从隐藏的 LaTeX annotation 提取源码，避免复制成重复或乱码的数学字形。只选中公式的一部分时，会复制完整公式。
- 已有 `$$...$$` 保持公式内容，只去掉两端空白。单个 `$...$` 不自动转换，避免把价格误识别为公式。
- 保留段落、列表和表格文字（表格用制表符分隔）；代码以 Markdown 代码标记保留，整段代码里的公式示例不会被转换。若只选中代码内的公式正文，仍可转换。
- 剪贴板写入纯文本；字体、颜色、图片、链接目标等富文本样式不保留。
- 不修改 ChatGPT 原有复制按钮和 Ctrl+C 行为。

## 飞书粘贴注意事项

飞书正文支持 `$$公式$$` 自动转换，但粘贴时有时仍显示普通文本。按官方建议，可删除公式末尾最后一个 `$` 再手动输入以触发。也可以用 `/gs` 打开公式编辑框，只粘贴公式正文（不带 `$$`）。插件只负责复制格式，无法控制飞书的粘贴解析。

参考：[飞书官方：在文档中使用公式](https://www.feishu.cn/hc/zh-CN/articles/894598450617)。

## 表格复制为 Markdown（1.1.0）

对话中的表格若缺少原生「复制表格」按钮，插件会在表格右边缘外侧 4px 处悬浮显示小复制图标（悬停提示「复制为 Markdown」），高度为表格顶部向下 4px，不独占一行，也不遮挡右对齐的单元格文字。位置按实际表格边缘计算，并随滚动和尺寸变化更新，不会对齐到更宽的外层容器。点击只复制这一张表格，输出标准的 Markdown 表头、分隔行和数据行。已有原生按钮的表格不会重复添加。

支持 DIL 表格、普通 HTML 表格以及后续动态生成的表格。切换聊天后会自动检查。复制时读取最新内容，生成期间点击可能得到尚未完整的表格。

第一行作为 Markdown 表头；单元格内换行转为 `<br>`；转义竖线和 Markdown 特殊字符；公式优先提取 LaTeX；合并单元格展开，内容置于左上格，其余格留空。保留文字，图片保留替代文字，不保留颜色和字体等样式。

## 权限与限制

仅申请右键菜单及剪贴板写入权限，内容脚本只在 `https://chatgpt.com/*` 运行。不上传内容、不读取剪贴板。图片渲染库随插件本地打包，无运行时 CDN 脚本。渲染含远程图片的区域时，库可能请求该图片以嵌入截图，不额外下载网页字体。

## Box 区域复制为图片（1.2.0）

最外层的 `data-d-component="box"` 展示区域内部右上角会出现统一的复制图标，悬停提示「复制整个区域为图片」。图标使用绝对定位，不额外占行；生成图片时自动排除。点击生成 PNG 并写入剪贴板，可直接粘贴到飞书、Word、聊天等支持图片的位置。

- 只在完整区域添加图标，嵌套的小 Box 和行内引用标记不重复添加。
- 截取点击时的显示状态，包括标题、文字、颜色、图形及区域根节点的完整尺寸，即使区域部分位于屏幕之外也会渲染。
- 不包含插件的复制按钮。默认使用 2 倍分辨率，大图会降低倍率以限制内存。
- 滚动子面板按当前显示内容渲染；跨域图片、受保护 Canvas、视频或嵌入页面可能无法生成图片，失败会明确提示。
- 字体使用本地可用的回退字体，可能与网页在线字体略有差异；动态交互复制为静态图片。

本地依赖：[html-to-image 1.11.13](https://github.com/bubkoo/html-to-image)，MIT 许可保存在 `vendor/html-to-image.LICENSE`。

## 整条回答复制 Markdown，保留 Mermaid（1.3.0）

回答底部的原生复制按钮旁增加一个蓝绿色复制图标，悬停提示「复制 Markdown（保留 Mermaid 源码）」。点击直接从当前回答生成 Markdown，图表输出为带 `mermaid` 语言标记的代码块，不会混入 SVG 样式。

不先读取系统剪贴板，也不调用或改变原生复制按钮。保留常见的标题、粗体、斜体、链接、列表、代码、表格与 LaTeX；图片仅保留替代文字，交互组件无法完整转成 Markdown。

Mermaid 源码优先读取页面属性，否则通过一个 MAIN 环境脚本读取当前图表 React 组件的 `clipboardContent` / `content` 字段。只在点击按钮时读取被标记回答中的图表源码，不读取完整聊天状态、不上传内容。React 内部字段并非稳定接口，后续网页更新可能需要适配。缺少任意图表源码时会提示失败，不会用样式或不完整内容覆盖剪贴板。

集成检查：`node tests/markdown-browser.cjs`（需要 Playwright 和 Chrome），覆盖多图表、源码恢复、排除 SVG/CSS、代码空白保留、回复范围和失败路径。

1.3.1 修正代码工具栏语言名混入正文的问题，将语言标记写入代码围栏（例如 ` ```java `）；引用段落只保留正常段落间隔，引用内的多行代码也逐行添加 `>` 并保留代码空白。

1.3.2 支持不使用 `<pre>` 的 `data-code-block-source` 代码区域；纯文本调用链等内容保持为 `text` 代码块，保留换行和缩进。

1.3.3 三类新增复制按钮统一反馈：复制成功后显示勾号和「已复制」提示，2 秒后恢复原图标和提示；失败时不显示成功勾号。连续复制会重新计时。

ChatGPT 的页面结构和公式渲染器变更后可能需要适配。公式若缺少 LaTeX 源码，会退回可用的页面文字；不保证所有数学语法都被飞书支持。

## 检查

```powershell
node --test tests/*.test.cjs
node --check background.js
node --check converter.js
node --check content.js
node --check boxes.js
```

另有可选浏览器集成检查 `node tests/browser-smoke.cjs`，需要环境中可用的 Playwright 和已安装的 Chrome。覆盖整条消息、选区、局部公式源码恢复、空选区以及剪贴板失败路径。

图片复制的浏览器检查：`node tests/boxes-browser.cjs`。在隔离测试页面验证 PNG 内容和尺寸、剪贴板条目、嵌套过滤、屏幕外完整区域、动态更新和失败提示，并生成 `tests/box-preview.png` 供视觉检查。剪贴板写入使用测试替身，不改动运行测试时用户的系统剪贴板。
